=====================================================================
  WHISKER BAY  -  Python edition, version 1.7.0
  A cat, a boat, and a chain of islands full of fish that really
  don't want to be caught. A real program, with online multiplayer that you
  and your friends host yourselves.
=====================================================================

---------------------------------------------------------------------
 NEW IN 1.7.0: THE BIG FISHING & POLISH UPDATE
---------------------------------------------------------------------

 - Fish on later islands are still challenging, but the reel pacing,
   bar width and line tension have been rebalanced.
 - Mythic and boss fights draw different tricks from larger pools, with
   separate cooldowns for each trick.
 - Stormbound and Moonlit mutations, plus three new cat accessories,
   give you more goals to chase.
 - Admins can spawn a shared island Mythic or a limited fish. Limited
   spawns are checked against the server's remaining stock.
 - Surge is F by default; Fishpedia is G. Custom controls are preserved.
 - Patch notes appear once after an update and are always in Settings >
   What's New or on the title screen.
 - The host server and every player need the same 1.7.0 game build.

 NEW IN 1.5.2: POLISH PASS AND RELEASE CLEANUP
---------------------------------------------------------------------

 NEW IN 1.5.0: RARITY REEL SCALING AND ROD SKILL SURGE
---------------------------------------------------------------------

 - Rarer fish now move more slowly during the reel fight, giving each
   rarity a more distinct, deliberate fight:
     Common ........ normal speed
     Uncommon ...... 1.3x slower
     Rare .......... 1.3x slower
     Epic .......... 1.75x slower
     Legendary ..... 2.5x slower
     Mythic ........ 4x slower
     Bosses ........ 5x slower (still have three stages)
 - Island speed scaling has been softened to balance the new rarity
   multipliers without removing the extra challenge of deeper waters.
 - NEW ROD SKILL: SURGE (Z by default). While the hook is underwater,
   Surge makes hook movement 40% faster and repels nearby Common,
   Uncommon and Rare fish for 3 seconds. It has a 10-second cooldown.
   Change its key in Settings > Controls.
 - Multiplayer protocol updated. All players AND the host server must
   use version 1.5.0; 1.4.4 clients and servers cannot mix with 1.5.0.

---------------------------------------------------------------------
 1. ONE-TIME SETUP  (every player does this once)
---------------------------------------------------------------------

 1. Install Python 3.8 or newer. It's free:
        https://www.python.org/downloads/
    WINDOWS: on the first installer screen, TICK the box
             "Add python.exe to PATH" before clicking Install.

 2. Unzip this folder somewhere easy to find, like your Desktop.
    (Don't run it from inside the zip.)

 That's it. The first time you start the game it downloads the one
 thing it needs (pygame-ce, a free game library). That needs internet
 once and takes about a minute.


---------------------------------------------------------------------
 2. PLAY
---------------------------------------------------------------------

   Windows : double-click  "Play Whisker Bay.bat"
   Mac     : double-click  "Play Whisker Bay.command"
             (first time only: right-click it > Open > Open, because
              Mac is careful with files from the internet)
   Linux   : run  ./play.sh      (or:  python3 play.py)

 WINDOWS SAYS "Smart App Control blocked..."?  Start it this way:
   1. Open the Whisker Bay folder.
   2. Click the address bar at the top of the window (where the
      folder's path is), type  cmd  and press Enter.
   3. In the black window, type   py play.py   and press Enter.

 On the title screen pick "Play on this computer" for single player,
 or "Play online with friends" (see part 3).

 CONTROLS (change any of them in Settings > Controls)
   Hold Space / mouse ..... charge a cast, let go to throw
   A / D or arrows ........ sail the boat, then steer the sinking hook
   S ...................... dive faster        W ... reel the hook up
   Space while sinking .... hold the hook at this depth
   R ...................... pull the line in
   A fish takes the bait .. it's hooked by itself, get ready to reel
   Reel bar ............... hold to push your bar right, let go to
                            slide left; keep the fish inside it
   Q or right-click ....... use your rod ability (when it says READY)
   B bag (and pets)   E shop   M sea chart   G Fishpedia   J quests
   F Surge (rod skill)
   Esc settings
   F11 fullscreen (you can also just drag the window bigger)


---------------------------------------------------------------------
 3. MULTIPLAYER
---------------------------------------------------------------------

 One person is the HOST. The host runs the server; then everyone,
 including the host, plays through "Play online with friends".

 THE HOST
   Windows : double-click  "Start Server.bat"
             (blocked by Smart App Control? Do the cmd trick from
              part 2 and type   py server.py   instead)
   Mac     : double-click  "Start Server.command"
   Linux   : run  ./start_server.sh      (or:  python3 server.py)

   - A window opens and shows addresses like   192.168.1.23:7777
     Keep that window open while people play.
   - Windows may ask whether Python may use the network.
     Click "Allow" (private networks is enough).
   - Want an invite code so strangers can't make accounts? Open
     "server_settings.json" (made the first time the server runs)
     with Notepad or TextEdit, put a code in "invite", save, and
     restart the server. You can also change the server's name and
     port there.
   - Commands you can type in the server window:
       list            who is online
       say <message>   talk to everyone as the host
       kick <name>     disconnect someone
       admin <name>    make someone an admin (F9 in the game)
       unadmin <name>  take it away again
       admins          list the admins
       stop            save everything and shut down

 EVERYONE
   1. Start the game > "Play online with friends".
   2. Server address: the address the host's server window shows,
      for example  192.168.1.23:7777
      (the host can type  localhost:7777)
   3. First time: pick a username and password > "Create account".
      If the server has an invite code, type it in too.
      After that: "Log in". Tick "Keep me logged in" to skip this.
   4. A new account can start fresh, or bring along an angler you
      already have on your computer.

 WHAT YOU GET ONLINE
   - See your friends' boats and cats on the same island, live.
   - Crew bonus: fishing on the same island as friends gives
     everyone +5% luck per friend (up to +15%).
   - T to chat. Keys 1-5 send emotes above your cat.
   - Key 5 is "GO GO GO!": if a friend on your island is fighting
     the Leviathan, your cheer makes their reel 25% faster.
   - Everyone hears about big catches (Epic and better, and rare
     mutations). When someone hooks the Leviathan, the whole server
     is told, and anyone on that island sees the storm roll in.
   - Tab: who's online, plus leaderboards (richest, highest level,
     best catch, Fishpedia, Leviathans slain, most fish).
   - Your progress is saved on the host's server (in its
     "server_data" folder), with a backup on your own computer.
     If the connection drops, keep fishing: it reconnects by itself
     and uploads your progress.


---------------------------------------------------------------------
 4. PLAYING WITH FRIENDS IN OTHER HOUSES
---------------------------------------------------------------------

 Same Wi-Fi works straight away. For friends somewhere else, pick ONE:

 A) PINGGY (nothing to install, ready in a minute, free)
    1. Start the server (part 3) and leave its window open.
    2. Open a second window: click the Whisker Bay folder's address
       bar, type  cmd  and press Enter.
    3. Type this and press Enter (7777 is the server's port; use
       yours if you changed it in server_settings.json):
           ssh -p 443 -R0:127.0.0.1:7777 tcp@a.pinggy.io
    4. The first time it asks "Are you sure you want to continue
       connecting?": type  yes  and press Enter.
       If it asks for a password: just press Enter, straight away.
       (If you wait too long it closes. Then run step 3 again.)
    5. It shows an address like
           tcp://rnxyz-12-34-56-78.a.free.pinggy.link:41234
       Friends type everything after  tcp://  into the Server
       address box. You (the host) can keep using localhost:7777.
    6. Keep both windows open. The free tunnel stops after 60
       minutes, and the address changes every time you start it
       again: just repeat step 3 and send friends the new one.
    Use 127.0.0.1 in step 3, not "localhost".

 B) TAILSCALE (one install, then the address never changes; free)
    1. Everyone installs Tailscale and signs in:
           https://tailscale.com/download
    2. The host invites the friends to their Tailscale network
       (in the Tailscale admin page: Users > Invite), or shares the
       host computer with them.
    3. Friends type the host computer's Tailscale address, which
       starts with 100. , plus :7777   for example  100.101.102.103:7777

 C) PORT FORWARDING (no extra apps, but you change router settings)
    1. In the host's router settings, forward TCP port 7777 to the
       host's computer (ask a parent if it's not your router).
    2. Friends use the host's public IP address (search "what is my
       IP" on the host's computer) plus :7777
    3. Set an invite code (part 3) so only friends can make accounts.

 D) AN ALWAYS-ON COMPUTER
    server.py runs on any computer with Python 3.8+: an old laptop,
    a Raspberry Pi, or a rented cloud server. It only needs incoming
    TCP port 7777 open. Then nobody's gaming PC has to stay on.


---------------------------------------------------------------------
 5. UPDATING TO A NEW VERSION  (your progress stays)
---------------------------------------------------------------------

 1. Close the game (and the server, if you're the host).
 2. Unzip the new version.
 3. Copy everything from the new folder INTO your old Whisker Bay
    folder, and choose "Replace the files" when Windows asks.
    The zip never contains your progress, so nothing is lost:
      saves                  your single-player anglers and settings
      server_data            (host) everyone's online accounts
      server_settings.json   (host) port, invite code, server name
 4. Start the game as usual.

 Everyone must update, and the host must start the NEW server.py:
 a 1.3 game can't join a 1.4 server (it shows a message saying so).
 Updating keeps your level, coins, fish, quests and islands.


---------------------------------------------------------------------
 6. GOOD TO KNOW
---------------------------------------------------------------------

 - Single-player saves are in the "saves" folder. Online accounts
   live on the host's computer in "server_data". To back up, copy
   those folders somewhere safe.
 - Settings > Saves can also copy a "save code" you can paste into
   Whisker Bay on another computer. Codes from the browser version
   work too.
 - Passwords are stored scrambled (hashed) on the server, but they
   travel over the network without encryption. Use a password you
   don't use anywhere else.
 - The server trusts the game it talks to, so it's made for
   friends, not strangers. Use an invite code if the server is
   reachable from the internet.
 - The Fishpedia (G) shows how hard each fish is to reel in, and
   the tricks of every fish you've caught.


---------------------------------------------------------------------
 7. IF SOMETHING GOES WRONG
---------------------------------------------------------------------

 "python is not recognized" or nothing happens (Windows)
     Reinstall Python and tick "Add python.exe to PATH". Or use the
     cmd trick from part 2 with  py play.py

 "Smart App Control blocked an app that may be unsafe" (Windows)
     Use the cmd trick from part 2:  py play.py  (or  py server.py)

 Mac says the file can't be opened
     Right-click it > Open. Or open Terminal, drag this folder in
     after typing  cd  and a space, press Enter, then type
     python3 play.py

 "Could not reach the server"
     Is the host's server window open? Is the address exactly what
     it shows, including the : and the number after it? Same Wi-Fi
     (or Tailscale on, or the Pinggy window still open)? Did the
     host click "Allow" on the firewall question?

 "The server closed the connection" (with Pinggy)
     The host's ssh command must say  127.0.0.1  (part 4, step 3).
     Close the Pinggy window, run it again, and send the new address.

 "Connection closed by ... port 443" (with Pinggy)
     The password question timed out. Run the ssh command again and
     press Enter straight away when it asks for a password.

 It installed pygame but won't start (Linux)
     The launcher sets up a private ".venv" folder by itself. If even
     that fails, run:  sudo apt install python3-venv python3-pip

 The game crashed
     The window shows what went wrong. Progress up to the last
     autosave (every 10 seconds) is safe.

 Game too small or too big
     Drag the window edges, or press F11 for fullscreen.

 Have fun out there. Watch the deep water.
